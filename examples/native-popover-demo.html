Calendar Component

The calendar uses the col-cal-popover component for the month and year selection dropdowns. Click on the month or year in the header to see the native popover in action.

Native Popover Features Used

  • popover="auto" - Automatic light-dismiss behavior
  • :popover-open - CSS pseudo-selector for styling open state
  • popovertarget - Declarative trigger connection
  • popovertargetaction="toggle" - Toggle behavior on click
  • showPopover() / hidePopover() - Programmatic control
  • toggle event - State change notifications

Usage Example

<!-- HTML -->
<col-cal locale="en-US"></col-cal>

<!-- JavaScript (ESM) -->
<script type="module">
  import "col-cal";
  import { supportsPopoverAPI } from "col-cal";

  // Check for native popover support
  if (supportsPopoverAPI()) {
    console.log("Using native Popover API");
  } else {
    console.log("Using fallback popover");
  }
</script>
